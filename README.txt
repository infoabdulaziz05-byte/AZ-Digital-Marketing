AZ DIGITAL MARKETING WEBSITE
============================

HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view the website in your browser.

HOW TO EDIT
- index.html: page text, contact details, social links and sections.
- style.css: colors, layout, fonts and responsive design.
- script.js: mobile navigation and WhatsApp contact form behavior.
- assets/logo.svg: custom brand logo.
